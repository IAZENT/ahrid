Figure 6. AHRID three-stage machine learning pipeline. Stage 1: K-Means (k=5) clusters employees into five behavioural archetypes from 6 interaction features; the resulting cluster label is appended as an explicit 18th feature to the Random Forest input vector. Stage 2: Random Forest classifier (200 trees, SMOTE-balanced, 4-class output) ingests the 18-feature vector and outputs a risk tier. Stage 3: SHAP TreeExplainer renders per-prediction attribution in plain language. Cluster sizes: C0=239, C1=266, C2=216, C3=185, C4=145; Silhouette=0.265. Classification accuracy: 90.95% (macro F1=0.889, PR-AUC=0.940, Cohen’s κ=0.868). Evaluated on 1,050 synthetic profiles across 8 threat categories.
