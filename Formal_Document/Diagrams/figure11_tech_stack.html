Figure 11. AHRID five-layer technology stack. Each layer communicates exclusively with its immediate neighbours via defined interfaces: the React SPA issues authenticated Axios requests to the Flask REST API; the API delegates to the Service Layer (adaptive engine, SHAP explainer, OSINT ingestion); the Service Layer reads trained artefacts from the ML Pipeline and persists results via SQLAlchemy ORM to PostgreSQL. APScheduler drives background threat-feed refresh (6-hour interval) and risk recalculation independently of the request cycle. Deployment: Vercel (frontend) and Render (backend + database).
