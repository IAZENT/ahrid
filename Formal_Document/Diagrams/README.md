## How to use with Canva

1. Open [canva.com](https://www.canva.com) and create a new design
2. Set canvas to **A4 Landscape** (297 x 210 mm) for most figures
3. Follow the layout spec in each MD file exactly
4. Use the exact hex colour codes specified
5. Use **Montserrat Bold** for headers and **Open Sans Regular** for body text (both free in Canva)
6. Export as **PNG, 300 DPI** (or highest available resolution)
7. In Word: delete the placeholder paragraph, insert the PNG image, apply APA7 caption from the MD file

---

## APA7 caption format reminder

Every figure in the thesis must follow this exact format:

```
[Image inserted here]

Figure N
Title of the figure in italics, title case
Note. Description of what the figure shows. Source attribution if applicable.
```

- "Figure N" line: bold
- Title line: italic, title case, left-aligned
- "Note." bold, rest of note sentence in normal weight
- All text: Times New Roman 12pt, same as body
