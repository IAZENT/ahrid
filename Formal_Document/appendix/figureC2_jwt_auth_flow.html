Figure C2. JWT Authentication and Token Lifecycle

Implementation-level sequence: login → protected access → token refresh → logout → blocklist

Access tokens (15 min) are short-lived to limit exposure; refresh tokens (30 days) enable seamless re-authentication. Server-side jti blocklisting on logout prevents token reuse even within the remaining validity window, satisfying the IPA 2075 §8 consent-withdrawal requirement (user can revoke access at any time).
