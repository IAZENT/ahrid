Figure B3. URL Difficulty Classification Decision Tree

Structural heuristics applied in priority order · first-match wins · evaluated per ingested URL

Checks are applied top-to-bottom in priority order; the first matching rule terminates evaluation. Level 1 (Obvious) signals include non-HTTPS schemes, free-hosting TLDs, and known typosquat character substitutions. Level 3 (Advanced) signals cover cloud infrastructure abuse and IDN homograph encoding — techniques that evade visual inspection. Level 2 (Subtle) is both an explicit outcome (brand-embedding attack) and the default fallback when no other signal is matched. IDN = Internationalised Domain Name · XP = Experience Points awarded on correct answer.
