Table B2. Scenario SQLAlchemy Model — Field Schema

PostgreSQL table: scenarios · populated by OSINT pipeline (source = "osint") and manual seeding (source = "manual")

Field Name Type Nullable Description
Identity & Classification
id PK Integer No Auto-incrementing primary key
category IDX String(64) No One of 8 training categories: phishing_email, smishing, vishing, password_hygiene, social_engineering, usb_baiting, data_handling, physical_security
difficulty IDX Integer No Difficulty level: 1 = Obvious (10 XP), 2 = Subtle (15 XP), 3 = Advanced (25 XP)
lure_type String(64) Yes One of 6 lure types assigned by the OSINT classifier; NULL for manually authored scenarios
source String(16) No osint — generated from ThreatFeedEntry; manual — admin-authored content
Question Content
title String(256) No Short scenario title displayed in the training UI (e.g., "Suspicious Invoice Email")
description Text No Scenario narrative presented to the employee as context before the question
question Text No The MCQ question stem (e.g., "What is the most suspicious element of this URL?")
options JSON No Array of 4 answer strings; index of correct answer stored in correct_option
correct_option Integer No Zero-based index into the options array identifying the correct answer
Feedback & Learning
red_flags JSON Yes Array of strings listing observable threat indicators shown after the employee answers
explanation Text Yes Post-answer explanation of why the correct option is correct and what the threat represents
learning_tip Text Yes Actionable advice to help the employee avoid this threat type in future
xp_reward Integer No XP points awarded on correct answer; derived from difficulty (10 / 15 / 25)
Targeting & Status
target_roles JSON Yes Array of job roles for which this scenario is relevant; NULL means applicable to all roles
is_active Boolean No Default TRUE; set FALSE to retire a scenario without deletion (soft delete)
threat_feed_id FK Integer Yes References threat_feed_entries.id; NULL for manually authored scenarios
created_at DateTime No UTC timestamp of scenario creation; used to surface recently added content

The options / red_flags / target_roles JSON columns allow variable-length lists without auxiliary tables. The threat_feed_id FK maintains traceability from training scenario back to the original OSINT entry for audit purposes. For the full entity relationship diagram, see Figure F1.
