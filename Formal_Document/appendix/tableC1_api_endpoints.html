Note: the thesis body text states 43 endpoints — this reflects an earlier development snapshot; the implemented system registers 61 routes across 8 blueprints. All non-public routes require a valid JWT in the Authorization: Bearer header. Rate limiting is applied globally via Flask-Limiter (200/day, 50/hour per IP by default).
