Figure F1. Entity Relationship Diagram (ERD)

Core AHRID database schema — SQLAlchemy models · PostgreSQL (prod) / SQLite (dev)

PK = Primary Key (UUID unless noted). FK = Foreign Key. Dashed lines indicate optional or non-FK relationships. TokenBlocklist carries no FK to users — tokens are validated by jti claim alone, so blocklist entries survive user deletion. All UUID primary keys use Python's uuid4. Timestamps use UTC throughout.
