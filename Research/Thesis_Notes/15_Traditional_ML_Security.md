# Traditional & ML-Based Security Systems

> Maps to **Objective 1** - Analyse the cybersecurity threat landscape

---

## Traditional Approaches
- Rule-based intrusion detection (Snort, Suricata)
- Signature-based antivirus
- Static security awareness training (annual presentations)
- Phishing simulations (GoPhish)
- Limitations: reactive, no personalization, high false-positive rates

## ML-Based Approaches
- Anomaly detection with unsupervised learning
- Classification-based threat detection (RF, SVM, Neural Networks)
- User & Entity Behaviour Analytics (UEBA)
- Adaptive training platforms
- Advantages: pattern recognition, personalization, continuous learning

## Comparison Table

| Aspect | Traditional | ML-Based |
|--------|------------|----------|
| Adaptivity | Static rules | Learns from data |
| Personalization | One-size-fits-all | Per-user profiling |
| Scalability | Manual rule updates | Automated retraining |
| Explainability | Transparent rules | Black box (unless XAI) |
| Cost | Low setup | Higher initial investment |

## Where AHRID Fits
- Combines ML classification (RF) with explainability (SHAP)
- Uses clustering for personalization without being fully black-box
- Live threat feeds keep it current (unlike static rule systems)
