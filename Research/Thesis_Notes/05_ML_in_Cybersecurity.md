# ML in Cybersecurity

> Overview of how machine learning is applied in the cybersecurity domain.

---

## Key Topics

### Classification in Security
- Spam/phishing detection
- Malware classification
- Insider threat detection
- **Random Forest** - why it's widely used (interpretability, robustness, ensemble strength)

### Clustering in Security
- User behaviour analytics (UBA)
- Anomaly detection
- Network traffic profiling
- **K-Means** - segmenting user risk profiles

### Handling Imbalanced Data
- Why security data is inherently imbalanced (few attacks, many normal events)
- **SMOTE** - synthetic oversampling to balance classes
- Other techniques: undersampling, class weights, ensemble methods

### Explainability (XAI) in Security
- The "black box" problem - why stakeholders need explanations
- **SHAP** - Shapley Additive Explanations for per-prediction transparency
- Regulatory context: GDPR right to explanation

### OSINT & Threat Intelligence
- Open-source threat feeds as training data
- Real-time ingestion for scenario generation
- AlienVault OTX, Phishing.Database
