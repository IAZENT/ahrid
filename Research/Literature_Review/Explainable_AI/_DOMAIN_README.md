# Explainable AI (SHAP / XAI)

Papers on model interpretability, SHAP values, explainability in security decision-making.

2. **Molnar (2020)** - Interpretable Machine Learning (free book)
3. **Arrieta et al.** - Explainable Artificial Intelligence (XAI): Concepts, taxonomies, opportunities
