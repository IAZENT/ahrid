# Machine Learning in Cybersecurity

Papers on ML-based risk scoring, Random Forest classifiers in security, insider threat detection, and predictive risk models.

## Key Search Terms
- `"random forest" "risk prediction" cybersecurity`
- `"machine learning" "insider threat" detection`
- `"user behavior analytics" "machine learning"`
- `"risk scoring" classification "security"`

## Suggested Starting Papers
1. **Buczak & Guven** - A Survey of Data Mining and Machine Learning Methods for Cyber Security Intrusion Detection
2. **Sarker et al.** - Machine Learning for Intelligent Data Analysis and Automation in Cybersecurity
3. **Breiman (2001)** - Random Forests (foundational paper, 100k+ citations)
