## 📝 How to Use This System

1. **Find a paper** → Create a note using the [[_PAPER_TEMPLATE]] in the appropriate domain folder
2. **Link it here** → Add `[[Paper Name]]` under the right domain heading above
3. **Update the table** → Increment counts as you progress
4. **Tag papers** → Use `#to-read`, `#reading`, `#done` tags in each paper note
5. **Use graph view** → Obsidian's graph will show connections between papers
